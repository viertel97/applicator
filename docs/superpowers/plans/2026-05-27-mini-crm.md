# Mini-CRM Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the application detail page into a per-app mini-CRM: structured interactions per channel, dynamic discard reasons, unified activity timeline, and a funnel/response-rate stats page.

**Architecture:** Three new SQLAlchemy models (`Interaction`, `DiscardReason`, `ApplicationEvent`) + single Alembic migration that backfills inquiry rows and seeds system discard reasons. Two new FastAPI routers + a stats service. Frontend gets new API modules, a log-interaction modal, a reusable discard-reason picker, a unified activity timeline panel, a settings page for reasons, and a stats page using `recharts`. Status changes auto-write `ApplicationEvent` rows via a `before_flush` session hook.

**Tech Stack:** FastAPI · SQLAlchemy 2.0 · Alembic · PostgreSQL · React + TanStack Query · recharts · Playwright

**Spec:** [`docs/superpowers/specs/2026-05-27-mini-crm-design.md`](../specs/2026-05-27-mini-crm-design.md)

## Conventions

- **TDD**: every backend task starts with a failing pytest, then implementation, then green run, then commit.
- **Tests**: integration tests live in `backend/tests/integration/` and use the existing `auth_user`/`db_session` fixtures (testcontainers Postgres).
- **Commits**: conventional commits. Each task ends with a commit. No `--no-verify`.
- **Status names**: `ApplicationStatus.discarded` already exists. `ApplicationStatus.applied` is the apply-confirmed state. The "responded" funnel stage is derived, not stored.
- **Inquiry refactor strategy**: when the user "marks inquiry sent", the backend creates an outgoing mail `Interaction` instead of stamping `application.inquiry_sent_at`. The persisted columns `inquiry_subject`/`inquiry_body`/`inquiry_sent_at` are dropped after backfill. The draft endpoint still returns subject+body but no longer writes them to `Application`.

```python
"""mini CRM: interaction, discard_reason, application_event

Revision ID: c4d5e6f7a8b9
Revises: b3c4d5e6f7a8
Create Date: 2026-05-27 00:00:00.000000

Drops application.{inquiry_subject, inquiry_body, inquiry_sent_at}; the
inquiry_subject/body content is preserved by being copied into a new
interaction row per application (created_from='inquiry_migration').
Renames application.discard_reason (text) -> discard_note (text); the
existing free-text content is preserved verbatim.
"""
from collections.abc import Sequence
from typing import Union

import sqlalchemy as sa
from alembic import op
from sqlalchemy.dialects import postgresql

revision: str = "c4d5e6f7a8b9"
down_revision: Union[str, Sequence[str], None] = "b3c4d5e6f7a8"
branch_labels: Union[str, Sequence[str], None] = None
depends_on: Union[str, Sequence[str], None] = None


SYSTEM_REASONS = [
    ("no_reply",        "No reply",          10),
    ("rejected",        "Rejected",          20),
    ("withdrew_self",   "Withdrew myself",   30),
    ("location",        "Location mismatch", 40),
    ("salary",          "Salary mismatch",   50),
    ("tech_mismatch",   "Tech mismatch",     60),
    ("seniority",       "Seniority mismatch", 70),
    ("posting_offline", "Posting offline",   80),
    ("duplicate",       "Duplicate",         90),
    ("other",           "Other",             100),
]


def upgrade() -> None:
    bind = op.get_bind()

    direction = postgresql.ENUM("out", "in", name="interactiondirection")
    channel = postgresql.ENUM(
        "mail", "linkedin", "phone", "portal", "xing", "other",
        name="interactionchannel",
    )
    sentiment = postgresql.ENUM(
        "positive", "neutral", "negative", "rejection", name="interactionsentiment",
    )
    created_from = postgresql.ENUM(
        "manual", "inquiry_migration", "graph_sync", name="interactioncreatedfrom",
    )
    event_kind = postgresql.ENUM(
        "status_change", "created", "inquiry_generated", "interview_scheduled",
        name="applicationeventkind",
    )
    for e in (direction, channel, sentiment, created_from, event_kind):
        e.create(bind, checkfirst=True)

    op.create_table(
        "discard_reason",
        sa.Column("id", postgresql.UUID(as_uuid=True), primary_key=True),
        sa.Column("user_id", postgresql.UUID(as_uuid=True), sa.ForeignKey("user.id"), nullable=False),
        sa.Column("slug", sa.String(64), nullable=False),
        sa.Column("label", sa.String(200), nullable=False),
        sa.Column("is_system", sa.Boolean(), nullable=False, server_default=sa.text("false")),
        sa.Column("is_archived", sa.Boolean(), nullable=False, server_default=sa.text("false")),
        sa.Column("sort_order", sa.Integer(), nullable=False, server_default="0"),
        sa.Column("created_at", sa.DateTime(), server_default=sa.func.now()),
        sa.UniqueConstraint("user_id", "slug", name="uq_discard_user_slug"),
    )

    op.create_table(
        "interaction",
        sa.Column("id", postgresql.UUID(as_uuid=True), primary_key=True),
        sa.Column("application_id", postgresql.UUID(as_uuid=True),
                  sa.ForeignKey("application.id"), nullable=False),
        sa.Column("occurred_at", sa.DateTime(), nullable=False, server_default=sa.func.now()),
        sa.Column("direction", direction, nullable=False),
        sa.Column("channel", channel, nullable=False),
        sa.Column("subject", sa.Text()),
        sa.Column("body", sa.Text()),
        sa.Column("contact_name", sa.Text()),
        sa.Column("contact_handle", sa.Text()),
        sa.Column("sentiment", sentiment, nullable=True),
        sa.Column("created_from", created_from, nullable=False, server_default="manual"),
        sa.Column("created_at", sa.DateTime(), server_default=sa.func.now()),
        sa.Column("updated_at", sa.DateTime(), server_default=sa.func.now()),
    )
    op.create_index("ix_interaction_app", "interaction", ["application_id"])
    op.create_index(
        "ix_interaction_app_occurred",
        "interaction",
        ["application_id", sa.text("occurred_at DESC")],
    )

    op.create_table(
        "application_event",
        sa.Column("id", postgresql.UUID(as_uuid=True), primary_key=True),
        sa.Column("application_id", postgresql.UUID(as_uuid=True),
                  sa.ForeignKey("application.id"), nullable=False),
        sa.Column("kind", event_kind, nullable=False),
        sa.Column("from_value", sa.String(64)),
        sa.Column("to_value", sa.String(64)),
        sa.Column("meta", sa.JSON()),
        sa.Column("occurred_at", sa.DateTime(), server_default=sa.func.now()),
    )
    op.create_index("ix_appevent_app", "application_event", ["application_id"])
    op.create_index("ix_appevent_occurred", "application_event", ["occurred_at"])

    # application FK additions + rename + drops
    op.add_column("application",
                  sa.Column("discard_reason_id", postgresql.UUID(as_uuid=True),
                            sa.ForeignKey("discard_reason.id"), nullable=True))
    op.add_column("application",
                  sa.Column("discard_interaction_id", postgresql.UUID(as_uuid=True), nullable=True))
    op.create_foreign_key(
        "fk_app_discard_interaction",
        "application", "interaction",
        ["discard_interaction_id"], ["id"],
        use_alter=True,
    )
    op.alter_column("application", "discard_reason", new_column_name="discard_note")

    # ----- backfill -----
    # 1. seed system reasons per user
    users = bind.execute(sa.text("SELECT id FROM \"user\"")).fetchall()
    import uuid as _uuid
    for u in users:
        for slug, label, sort in SYSTEM_REASONS:
            bind.execute(
                sa.text(
                    "INSERT INTO discard_reason "
                    "(id, user_id, slug, label, is_system, sort_order) "
                    "VALUES (:i, :u, :s, :l, true, :o)"
                ),
                {"i": _uuid.uuid4(), "u": u.id, "s": slug, "l": label, "o": sort},
            )

    # 2. backfill inquiry rows into interaction
    inquiries = bind.execute(sa.text(
        "SELECT id, inquiry_subject, inquiry_body, inquiry_sent_at "
        "FROM application WHERE inquiry_sent_at IS NOT NULL"
    )).fetchall()
    for row in inquiries:
        bind.execute(
            sa.text(
                "INSERT INTO interaction "
                "(id, application_id, occurred_at, direction, channel, "
                "subject, body, created_from) "
                "VALUES (:i, :a, :o, 'out', 'mail', :s, :b, 'inquiry_migration')"
            ),
            {
                "i": _uuid.uuid4(),
                "a": row.id,
                "o": row.inquiry_sent_at,
                "s": row.inquiry_subject,
                "b": row.inquiry_body,
            },
        )

    # 3. map discarded apps' discard_note to a seeded reason where the text
    #    matches a system label case-insensitively
    bind.execute(sa.text(
        """
        UPDATE application a SET discard_reason_id = dr.id
          FROM discard_reason dr
         WHERE a.user_id = dr.user_id
           AND a.status = 'discarded'
           AND a.discard_note IS NOT NULL
           AND lower(trim(a.discard_note)) = lower(dr.label)
        """
    ))

    # 4. one application_event row per application: kind=created
    bind.execute(sa.text(
        "INSERT INTO application_event "
        "(id, application_id, kind, occurred_at) "
        "SELECT gen_random_uuid(), id, 'created', created_at FROM application"
    ))

    # ----- drop legacy columns -----
    op.drop_column("application", "inquiry_subject")
    op.drop_column("application", "inquiry_body")
    op.drop_column("application", "inquiry_sent_at")


def downgrade() -> None:
    # destructive: inquiry backfill data is not reconstructible
    op.add_column("application", sa.Column("inquiry_subject", sa.Text(), nullable=True))
    op.add_column("application", sa.Column("inquiry_body", sa.Text(), nullable=True))
    op.add_column("application", sa.Column("inquiry_sent_at", sa.DateTime(), nullable=True))
    op.drop_constraint("fk_app_discard_interaction", "application", type_="foreignkey")
    op.drop_column("application", "discard_interaction_id")
    op.drop_column("application", "discard_reason_id")
    op.alter_column("application", "discard_note", new_column_name="discard_reason")
    op.drop_index("ix_appevent_occurred", table_name="application_event")
    op.drop_index("ix_appevent_app", table_name="application_event")
    op.drop_table("application_event")
    op.drop_index("ix_interaction_app_occurred", table_name="interaction")
    op.drop_index("ix_interaction_app", table_name="interaction")
    op.drop_table("interaction")
    op.drop_table("discard_reason")
    for name in (
        "applicationeventkind", "interactioncreatedfrom",
        "interactionsentiment", "interactionchannel", "interactiondirection",
    ):
        op.execute(f"DROP TYPE IF EXISTS {name}")
```

    ("withdrew_self",   "Withdrew myself",    30),
    ("location",        "Location mismatch",  40),

def _derive_slug(label: str) -> str:
    norm = unicodedata.normalize("NFKD", label.strip().lower())
    ascii_only = norm.encode("ascii", "ignore").decode()
    underscored = re.sub(r"[^a-z0-9]+", "_", ascii_only).strip("_")
    return (underscored or "reason")[:64]


def _unique_slug(base: str, taken: set[str]) -> str:
    if base not in taken:
        return base
    i = 2
    while f"{base}_{i}" in taken:
        i += 1
    return f"{base}_{i}"


def seed_system_reasons(db: Session, user_id: uuid.UUID) -> None:
    existing = {
        r.slug for r in db.query(DiscardReason).filter_by(user_id=user_id).all()
    }
    for slug, label, sort in SYSTEM_REASONS:
        if slug in existing:
            continue
        db.add(DiscardReason(
            user_id=user_id, slug=slug, label=label,
            is_system=True, sort_order=sort,
        ))


class ReasonOut(BaseModel):
    id: uuid.UUID
    slug: str
    label: str
    is_system: bool
    is_archived: bool
    sort_order: int
    usage_count: int

    model_config = {"from_attributes": True}

class ReasonPatch(BaseModel):
    label: str | None = None
    is_archived: bool | None = None
    sort_order: int | None = None


def _to_out(db: Session, r: DiscardReason) -> ReasonOut:
    cnt = db.query(func.count(Application.id)).filter(
        Application.discard_reason_id == r.id
    ).scalar() or 0
    return ReasonOut(
        id=r.id, slug=r.slug, label=r.label,
        is_system=r.is_system, is_archived=r.is_archived,
        sort_order=r.sort_order, usage_count=cnt,
    )


@router.get("", response_model=list[ReasonOut])
def list_reasons(
    db: Annotated[Session, Depends(db_dep)],
    user: Annotated[User, Depends(current_user)],
    include_archived: int = Query(0),
):
    if db.query(DiscardReason).filter_by(user_id=user.id).count() == 0:
        seed_system_reasons(db, user.id)
        db.commit()
    q = db.query(DiscardReason).filter_by(user_id=user.id)
    if not include_archived:
        q = q.filter_by(is_archived=False)
    rows = q.order_by(DiscardReason.sort_order, DiscardReason.label).all()
    return [_to_out(db, r) for r in rows]


@router.post("", response_model=ReasonOut)
def create_reason(
    body: ReasonCreate,
    db: Annotated[Session, Depends(db_dep)],
    user: Annotated[User, Depends(current_user)],
):
    if not body.label.strip():
        raise HTTPException(400, "label required")
    base = _derive_slug(body.slug) if body.slug else _derive_slug(body.label)
    taken = {
        r.slug for r in db.query(DiscardReason).filter_by(user_id=user.id).all()
    }
    slug = _unique_slug(base, taken)
    max_sort = db.query(func.coalesce(func.max(DiscardReason.sort_order), 0)).filter_by(
        user_id=user.id
    ).scalar() or 0
    r = DiscardReason(
        user_id=user.id, slug=slug, label=body.label.strip(),
        is_system=False, sort_order=max_sort + 10,
    )
    db.add(r); db.commit(); db.refresh(r)
    return _to_out(db, r)


@router.patch("/{rid}", response_model=ReasonOut)
def patch_reason(
    rid: uuid.UUID,
    body: ReasonPatch,
    db: Annotated[Session, Depends(db_dep)],
    user: Annotated[User, Depends(current_user)],
):
    r = db.get(DiscardReason, rid)
    if not r or r.user_id != user.id:
        raise HTTPException(404, "not found")
    if body.label is not None:
        r.label = body.label.strip()
    if body.is_archived is not None:
        r.is_archived = body.is_archived
    if body.sort_order is not None:
        r.sort_order = body.sort_order
    db.commit(); db.refresh(r)
    return _to_out(db, r)


@router.delete("/{rid}", status_code=204)

```python
from datetime import datetime, timezone

from sqlalchemy import event, inspect
from sqlalchemy.orm import Session

from app.db.models import Application, ApplicationEvent, ApplicationEventKind


def _record_status_changes(session: Session, flush_context, instances) -> None:
    pending: list[ApplicationEvent] = []
    for obj in session.dirty:
        if not isinstance(obj, Application):
            continue
        hist = inspect(obj).attrs.status.history
        if not hist.has_changes():
            continue
        old = hist.deleted[0] if hist.deleted else None
        new = hist.added[0] if hist.added else obj.status
        pending.append(ApplicationEvent(
            application_id=obj.id,
            kind=ApplicationEventKind.status_change,
            from_value=old.value if old is not None else None,
            to_value=new.value if new is not None else None,
            occurred_at=datetime.now(timezone.utc),
        ))
    for ev in pending:
        session.add(ev)


def register() -> None:
    event.listen(Session, "before_flush", _record_status_changes)
```

```python
import uuid
from collections import defaultdict
from datetime import datetime, timedelta
from typing import Annotated

from fastapi import APIRouter, Depends, Query
from pydantic import BaseModel
from sqlalchemy import func, select, text
from sqlalchemy.orm import Session

from app.api.deps import current_user, db_dep
from app.db.models import (
    Application, ApplicationStatus, DiscardReason, Interaction,
    InteractionChannel, InteractionDirection, Interview, User,
)

router = APIRouter(prefix="/api/stats", tags=["stats"])


class FunnelStage(BaseModel):
    stage: str
    count: int


class ChannelRate(BaseModel):
    channel: str
    outgoing: int
    responses: int
    rate: float


class DiscardBreakdown(BaseModel):
    slug: str
    label: str
    count: int


class WeeklyVolume(BaseModel):
    week: str
    applied: int
    discarded: int
    responses: int


class FunnelOut(BaseModel):
    totals: dict
    funnel: list[FunnelStage]
    response_rate_by_channel: list[ChannelRate]
    avg_time_to_reply_hours: dict
    discard_breakdown: list[DiscardBreakdown]
    weekly_volume: list[WeeklyVolume]


def _between(col, fr: datetime | None, to: datetime | None):
    out = []
    if fr is not None: out.append(col >= fr)
    if to is not None: out.append(col <= to)
    return out


@router.get("/funnel", response_model=FunnelOut)
def funnel(
    db: Annotated[Session, Depends(db_dep)],
    user: Annotated[User, Depends(current_user)],
    fr: datetime | None = Query(default=None, alias="from"),
    to: datetime | None = Query(default=None),
):
    base = db.query(Application).filter(
        Application.user_id == user.id,
        Application.deleted_at.is_(None),
        *_between(Application.created_at, fr, to),
    )
    apps = base.all()
    aids = [a.id for a in apps]

    total = len(apps)
    by_status: dict[str, int] = defaultdict(int)
    for a in apps:
        by_status[a.status.value] += 1

    # all in interactions for these apps
    in_rows: list[Interaction] = (
        db.query(Interaction)
          .filter(Interaction.application_id.in_(aids) if aids else False,
                  Interaction.direction == InteractionDirection.in_)
          .all() if aids else []
    )
    responded_app_ids = {it.application_id for it in in_rows}

    interview_app_ids = {
        i.application_id for i in (
            db.query(Interview).filter(Interview.application_id.in_(aids)).all()
            if aids else []
        )
    }

    funnel_stages = [
        FunnelStage(stage="created", count=total),
        FunnelStage(stage="applied",
                    count=sum(1 for a in apps if a.status != ApplicationStatus.draft)),
        FunnelStage(stage="responded", count=len(responded_app_ids)),
        FunnelStage(stage="interview", count=len(interview_app_ids)),
        FunnelStage(stage="offer", count=by_status.get("offer", 0)),
        FunnelStage(stage="accepted", count=by_status.get("accepted", 0)),
    ]

    # response rate per channel — same-channel + ordering rule
    out_rows: list[Interaction] = (
        db.query(Interaction)
          .filter(Interaction.application_id.in_(aids) if aids else False,
                  Interaction.direction == InteractionDirection.out)
          .all() if aids else []
    )
    earliest_out: dict[tuple[uuid.UUID, str], datetime] = {}
    for it in out_rows:
        key = (it.application_id, it.channel.value)
        if key not in earliest_out or it.occurred_at < earliest_out[key]:
            earliest_out[key] = it.occurred_at

    out_apps_per_channel: dict[str, set[uuid.UUID]] = defaultdict(set)
    for (aid, ch), _ in earliest_out.items():
        out_apps_per_channel[ch].add(aid)

    response_apps_per_channel: dict[str, set[uuid.UUID]] = defaultdict(set)
    reply_deltas: dict[str, list[float]] = defaultdict(list)
    for it in in_rows:
        ch = it.channel.value
        key = (it.application_id, ch)
        out_at = earliest_out.get(key)
        if out_at and it.occurred_at > out_at:
            if it.application_id not in response_apps_per_channel[ch]:
                response_apps_per_channel[ch].add(it.application_id)
                reply_deltas[ch].append(
                    (it.occurred_at - out_at).total_seconds() / 3600.0
                )

    channel_rates: list[ChannelRate] = []
    for ch in sorted({c for _, c in earliest_out.keys()}):
        out_count = len(out_apps_per_channel[ch])
        in_count = len(response_apps_per_channel[ch])
        rate = (in_count / out_count) if out_count else 0.0
        channel_rates.append(ChannelRate(
            channel=ch, outgoing=out_count, responses=in_count, rate=rate,
        ))

    avg_reply = {
        ch: round(sum(v) / len(v), 1) for ch, v in reply_deltas.items() if v
    }

    # discard breakdown
    discard_rows = (
        db.query(DiscardReason.slug, DiscardReason.label, func.count(Application.id))
          .join(Application, Application.discard_reason_id == DiscardReason.id)
          .filter(Application.user_id == user.id,
                  Application.deleted_at.is_(None))
          .group_by(DiscardReason.slug, DiscardReason.label)
          .order_by(func.count(Application.id).desc())
          .all()
    )
    discard_breakdown = [
        DiscardBreakdown(slug=s, label=l, count=c) for s, l, c in discard_rows
    ]

    # weekly volume: ISO week, applied/discarded/responses
    weekly: dict[str, dict[str, int]] = defaultdict(lambda: {
        "applied": 0, "discarded": 0, "responses": 0,
    })
    for a in apps:
        wk = a.created_at.strftime("%G-W%V")
        if a.status != ApplicationStatus.draft:
            weekly[wk]["applied"] += 1
        if a.status == ApplicationStatus.discarded:
            weekly[wk]["discarded"] += 1
    for it in in_rows:
        wk = it.occurred_at.strftime("%G-W%V")
        weekly[wk]["responses"] += 1
    weekly_volume = [
        WeeklyVolume(week=w, **vals) for w, vals in sorted(weekly.items())
    ]

    totals = {
        "applications": total,
        "applied": sum(1 for a in apps if a.status != ApplicationStatus.draft),
        "discarded": by_status.get("discarded", 0),
        "active": sum(
            1 for a in apps
            if a.status not in (
                ApplicationStatus.discarded, ApplicationStatus.rejected,
                ApplicationStatus.withdrawn, ApplicationStatus.accepted,
            )
        ),
    }

    return FunnelOut(
        totals=totals,
        funnel=funnel_stages,
        response_rate_by_channel=channel_rates,
        avg_time_to_reply_hours=avg_reply,
        discard_breakdown=discard_breakdown,
        weekly_volume=weekly_volume,
    )
```

import { useQuery } from "@tanstack/react-query";
import { timeline, type TimelineRow } from "../api/interactions";

function iconFor(row: TimelineRow) {
  if (row.kind === "interaction") {
    return row.data.direction === "out" ? "→" : "←";
  }
  if (row.kind === "interview") return "🎤";
  return "•";
}

function describe(row: TimelineRow): string {
  if (row.kind === "interaction") {
    const it = row.data;
    const dir = it.direction === "out" ? "Sent" : "Received";
    return `${dir} via ${it.channel}${it.subject ? ` — ${it.subject}` : ""}`;
  }
  if (row.kind === "interview") {
    return `Interview (${row.data.kind}) — ${row.data.outcome}`;
  }
  const ev = row.data;
  if (ev.kind === "status_change") return `Status: ${ev.from} → ${ev.to}`;
  return ev.kind;
}

export function ActivityTimeline({ appId }: { appId: string }) {
  const q = useQuery({
    queryKey: ["application-timeline", appId],
    queryFn: () => timeline.get(appId),
  });
  if (!q.data) return <div className="text-sm text-slate-500">Loading…</div>;
  if (q.data.length === 0)
    return <div className="text-sm text-slate-500">No activity yet.</div>;
  return (
    <ul className="divide-y border rounded">
      {q.data.map((row, i) => (
        <li key={i} className="p-2 flex gap-3">
          <span className="text-slate-400 w-5 text-center">{iconFor(row)}</span>
          <div className="flex-1">
            <div className="text-sm">{describe(row)}</div>
            <div className="text-xs text-slate-500">
              {new Date(row.at).toLocaleString()}
            </div>
            {row.kind === "interaction" && row.data.body && (
              <div className="text-sm text-slate-700 mt-1 whitespace-pre-wrap">
                {row.data.body}
              </div>
            )}
          </div>
        </li>
      ))}
    </ul>
  );
}

## Risks / Watch-outs

1. **`InteractionDirection.in_`**: Python keyword collision. Tests must use `InteractionDirection.in_` but the SQL/JSON value remains `"in"`. Double-check Pydantic accepts the alias on input (it does via enum value).
2. **Migration enum collision**: existing DB may already have a `name="interactionchannel"` enum from somewhere. The migration uses `checkfirst=True`. If an unrelated type with the same name exists, the migration will fail loudly — that's preferred to silent shadowing.
3. **`use_alter=True` FK to interaction**: needed because the rename in step 5 of the migration happens before `discard_interaction_id` FK creation; using `use_alter` makes alembic emit a deferred ADD CONSTRAINT, avoiding circular-create issues.
4. **`_record_status_changes` and SQLAlchemy `_value_`**: `inspect(obj).attrs.status.history.deleted` returns enum instances. Guard against `None` from initial inserts (the test for "no event on unchanged" covers this implicitly because `has_changes()` will be False).
5. **Backfill DELETE columns**: this is one-way. The migration's pre-deploy note in the spec requires a manual backup.
6. **Stats endpoint correctness for the "responded" stage vs per-channel rate**: spec is explicit and tested (Task 9).
